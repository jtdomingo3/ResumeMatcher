# Software Engineering Career Progression & Competency Framework

## 1. Career Levels and Expectations

### Junior Software Engineer (0 - 2 Years)
- **Scope:** Task-level execution with guidance.
- **Focus:** Learning codebase patterns, writing clean unit tests, mastering Git workflows, debugging local issues.
- **Deliverables:** Well-tested pull requests, adherence to style guides, active engagement in code reviews.

### Mid-Level Software Engineer (2 - 5 Years)
- **Scope:** Feature-level ownership with autonomy.
- **Focus:** Designing component architecture, choosing appropriate data structures and databases, optimizing API contracts.
- **Deliverables:** Complete feature deliveries, cross-service integrations, robust error handling, automated CI/CD configurations.

### Senior Software Engineer (5 - 8 Years)
- **Scope:** System-level and team-level impact.
- **Focus:** System resilience, high-throughput scalability, technical trade-off decisions, mentoring junior/mid developers.
- **Deliverables:** Architectural RFCs, performance optimizations under heavy load, reliability improvements (observability, tracing).

### Lead / Staff Software Engineer (8+ Years)
- **Scope:** Cross-team and organizational architecture.
- **Focus:** Multi-year technical roadmaps, aligning engineering capabilities with commercial strategy, pioneering new technology adoption.
- **Deliverables:** Organization-wide platforms, disaster recovery protocols, team engineering velocity enablement.
